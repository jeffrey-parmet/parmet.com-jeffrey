AdHawk is a tool which tracks political ads on platforms including [CTV](https://adimpact.com/), [Google/YouTube](https://adstransparency.google.com/political?region=US&topic=political), [Meta (Facebook, Insta)](https://www.facebook.com/ads/library/?active_status=all&ad_type=political_and_issue_ads&country=SE), and [Snapchat](https://www.snap.com/political-ads).

For technical folks: Python (FastAPI, DuckDb, SQLAlchemy), React (Typescript, Chakra), AWS (ECS, S3, EC2, Amplify), Auth0, BetterStack, PostHog.
